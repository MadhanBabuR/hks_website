# Photographs

The site currently shows labelled placeholders from `images/placeholders/`, generated by
`node tools/placeholders.mjs`. To use a real photo, save it here and change the matching
`<img src>` in `src/pages/*.html`, then run `node build.mjs`.

Note consent and permissions here for every photo you add. Photos of children need parental
consent; photos owned by other accounts or credited photographers need their permission.
